Descrição técnica fornecida pela universidade:

Tema do PIV: 
Desenvolver um sistema IoT com captura, análise e processamento de dados. 

O sistema pode ser tanto autônomo quanto ter uma interface web ou por dispositivo móvel.

Resolução de problemas; sistemas embarcados; protocolos IoT; plataformas de ingestão e análise de dados; nuvem; processamento digital de sinais; controle de versão; testes; integração contínua.

Desenvolver um sistema IoT com captura, análise e processamento de dados. O sistema pode ser tanto autônomo quanto ter uma interface web ou por dispositivo móvel.

Descrição da aplicação dos requisitos da disciplina PI V, aplicados no desenvolvimento do nosso projeto:

Desenvolver um software com framework web ou aplicativo: requisito atendendo desenvolvido em HTML e CSS aplicação Web (site de vagas) com framework Bootstrap.

Utilize banco de dados: requisito atendendo desenvolvido no Back-End banco de dados para cadastro e login de usuários com SQL SERVER como SGBD e SQL como linguagem de consulta de dados.

Inclui script web (Javascript): requisito atendendo aplicação Web (site de vagas) desenvolvido com Javascript no Back-End para interatividade das páginas web, bem como, com o banco de dados.

Inclui nuvem: requisito atender aplicação Web hospedada e rodar no servidor em nuvem do Infinity free.

Inclui acessibilidade: requisito atendendo à utilização do framework Bootstrap, para desenvolvimento responsivo, técnica que adapta a apresentação de um site para que ele funcione bem em diferentes dispositivos.

Inclui controle de versão e integração contínua: Ambos os requisitos foram atendidos com a utilização do GIT e do GitHUb.

Incluir testes: requisito atendendo com a utilização de manual de teste utilizando a ferramenta de desenvolvedor do Google Chrome utilizando o F12 para testar o tamanho das telas em equipamentos diferentes, os scripts em execução, bem como, a verificação de erros.

Incluir um dos seguintes requisitos: uso e fornecimento de API, análises de dados e IoT: requisito atendendo utilizando a análise de dados com linguagem Python utilizada como Bibliotecas: Pandas, Matplotlib, Seaborn, Scikit-learn, Statsmodels.
